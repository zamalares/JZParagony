Wklej token dostępowy GitHub (PAT), aby aplikacja mogła automatycznie pobierać i zapisywać paragonów w repozytorium.

Jak wygenerować Token (PAT)?

  1. Wejdź na GitHub -> Settings -> Developer Settings.
  2. Personal access tokens -> Tokens (classic).
  3. Kliknij Generate new token i zaznacz uprawnienie repo.
  4. Wklej skopiowany token powyżej.
